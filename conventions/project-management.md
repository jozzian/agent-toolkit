# Project Management Vocabulary

A shared naming standard for the units used to scope and track work.

## The terms

```
Theme
└── Objective
    └── Goal (aka Key Result)
        └── Milestone
            └── Task
```

## Outcomes

Every level below Theme has an outcome, defined before the work starts.

An outcome is what will be true once the work is done, stated so that
someone other than the person who did the work can verify it.

It can be a deliverable (so a concrete output like a document, a file, a
running tool), a state (a check passes, a risk is retired), or a decision
(a proposal was accepted).

Only a deliverable produces an output. A state or a decision is checked
directly.

## Theme

A strategic direction that work aligns to. It names an ambition, not a
fact to check.

- A Theme is never "reached" and has no outcome of its own.
- Wording is present tense and aspirational.
- A Theme groups a set of Objectives and explains why they were chosen
  together.

## Objective

A grouping of Goals that belong together, reached once every Goal beneath
it has been reached.

- Wording is present tense, an ambition rather than a fact, so it is not
  itself SMART and carries no date.
- It becomes checkable only through its Goals.
- An Objective needs at least one Goal, or it is just a label.
- If none of its Goals are dated yet, say so rather than treating it as
  equivalent to an Objective with real accountability underneath it.

## Goal (aka Key Result)

The Objective's Key Result: the measurable, dated proof that the Objective
is progressing.

- Wording is past tense, as if it had already happened, for example "has
  reached conformance with the spec" or "was accepted by the repository
  owner." This makes it a fact that is either true or not.
- SMART is the ambition here, a Goal can fall short on a letter or two as
  long as the gap is known.
- A Goal breaks down into Milestones, and is reached once every Milestone
  is reached.

## Milestone

A sequential step toward a Goal, smaller and more concrete than the Goal
itself.

- Either reached or not, no partial credit.
- Wording is the same past tense, achieved form as a Goal.
- Unlike a Goal, a Milestone must be fully SMART, since one that cannot be
  checked cannot prove the Goal is getting closer.
- State explicitly what is out of scope.

## Task

The unit of execution: a single piece of work that one person or one agent
session can finish in one sitting.

- Wording is a verb in the present tense, starting with an imperative
  action word: Create, Add, Rename, Migrate, Remove.
- A Task belongs to a Milestone and has an outcome, but does not need to
  be SMART.
