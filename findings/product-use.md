# Product-use findings — agent-toolkit

This toolkit's own log, per `approaches/product-use-learning-loop.md` and
`outputs/findings-log.md`. Append-only; entries are updated in place as
they move through that loop's `Status` values, not replaced or removed.

No entries yet. This toolkit is process/documentation, not a product with
a UI or a runtime a person "uses" the way a consuming project's own
prototype is used — so this file may stay empty for a long time, and
that's expected, not a gap to fill artificially. It exists now as the
reference shape for what an adopting project's own `findings/product-
use.md` looks like. `docverify-backend/PAPERCUT.md` is a real, populated
example of a repo-local friction log, but it predates this two-loop split
and isn't a clean example of either one alone: its own `agent` category
(process friction) is working-method-shaped, while its `system`/
`application` categories are something this toolkit's two-loop model
doesn't map cleanly onto either loop, not a worked example of
`product-use.md` specifically. See `findings/working-method.md` in this
same directory for this toolkit's own populated log instead.
