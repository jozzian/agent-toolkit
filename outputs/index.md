# Outputs

An output specifies the required structure and format of a recurring
deliverable. It may include a template where a template adds practical
value. This directory holds the specification only; it is not a folder
for generated project content. Each consuming project owns its own
generated files.

| Output | Specifies |
|---|---|
| [Artifact Adoption Ledger](artifact-adoption-ledger.md) | A project-local record of which toolkit artifacts a project uses, its adoption status, and any deliberate deviation. |
