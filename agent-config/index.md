# Agent configuration

Optional, tool-specific discovery and automation. An adapter points at
the canonical files (`AGENTS.md`, `README.md`, `conventions/`,
`routines/`); it never restates or redefines them.

Claude is the one implemented adapter, under `agent-config/claude/`. A
Codex, OpenCode, or any other adapter gets its own sibling directory
once there is a working, verified integration, not ahead of one
existing. No speculative placeholders.
