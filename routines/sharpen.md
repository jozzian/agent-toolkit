# Sharpen

Apply this routine to the piece of writing at hand: a draft, a message, a
document, or a section of one. Follow every instruction below on the
content you are given.

## What to do

1. Lead with the answer, the conclusion, the ask, or a context-setting
   summary. Do not save the point for the end.
2. Remove redundancy, filler, unsupported logic, and scope the request
   did not ask for.
3. If the input is a proposed document or section, ask first whether it
   needs to exist at all. Say so if it does not, instead of improving
   text that should be deleted.
4. Use no contractions.
5. Use no em dashes or en dashes. Use a period, a comma, a colon, or a
   full word such as "and" instead.
6. Cut AI-writing tells on sight, including:
   - Filler phrases that add words without adding meaning ("it is worth
     noting that," "in order to," "at the end of the day").
   - Inflated words used where a plain one would do ("utilize" for
     "use," "leverage" for "use," "facilitate" for "help").
   - Stacked hedging ("it seems like it might potentially," "could
     possibly," more than one hedge on the same claim).
   - Artificial tricolons: a list of exactly three items reached for
     rhythm rather than because the content actually has three parts.
   - Redundant summaries that restate a point the reader just read.
7. Use no emoji, unless the source material already uses them
   deliberately and removing them would lose information.
8. Do not add headings to a short message. A heading earns its place by
   organizing more than one section; a two-sentence reply does not need
   one.
9. Return only the requested rewritten or drafted content. Do not wrap it
   in an explanation of what changed, unless the change itself is what
   was asked for.
10. Say plainly when a draft is already good, or when the honest output
    is that nothing should be written. Do not manufacture edits to look
    useful.
11. Calibrate the size of the intervention to the actual problem. A
    one-word fix stays a one-word fix; do not rewrite a paragraph to
    justify having been asked to look at it.
12. Retain useful examples from the source. Edit them only where clarity
    or consistency with the rest of the piece requires it.

## Invocation

Explicit invocation of this routine applies it to whatever piece of
writing is in front of it at that moment.

A consuming project or an agent configuration may designate this routine
as its default writing routine, so that it runs without being asked each
time. Pasting this file into an AI chat may establish it for that
conversation, subject to how that interface actually handles pasted
instructions; some interfaces hold pasted instructions for the rest of
the conversation, others do not.

This file, by itself, cannot make either of those things happen
automatically. It states what the routine does once invoked; whether it
runs by default in a given tool or chat is a property of that tool's or
that chat's own configuration, not of this file.
